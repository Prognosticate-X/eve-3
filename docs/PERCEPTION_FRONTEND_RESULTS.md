## 1. 核心理论与机制设计

面对视觉语言模型（VLM）与图像分割前端不可避免的噪声（漏检、误检、坐标抖动与属性误判），传统的一阶离散符号系统会因单个属性不匹配而直接崩溃，或者产生灾难性的假阳性结论。Phase 10 构建了分层场景图神经符号感知前端：

```

|  - 2D 离散网格矩阵 (ARC-Style Grid) 或 连续物理位姿 (Continuous State)   |
+-------------------------------------------------------------------------+

                                    v
+-------------------------------------------------------------------------+

|  - 连通域连通分析 / 实体分割 (Connected Components)                     |
|  - 实体节点提取: ObjectNode (id, category, position, bbox, attributes)  |
|  - 空间拓扑关系推理: RelationEdge (left_of, right_of, above, below, touching)|
|  - 参数化感知噪声模型: 属性偏置、空间高斯抖动、漏检与幻觉虚警            |
+-------------------------------------------------------------------------+
                                    |
                                    v
+-------------------------------------------------------------------------+
|  SceneGraph & PredicateState (结构化场景图与谓词状态)                    |
```

### 1.1 场景图结构与高阶谓词推演

定义场景图 $\mathcal{G} = (\mathcal{V}, \mathcal{E})$：
- **实体节点** $v_i \in \mathcal{V}$：$v_i = (\text{id}_i, \text{cat}_i, \mathbf{p}_i, \mathbf{b}_i, \mathbf{a}_i, c_i)$，其中 $\mathbf{p}_i \in \mathbb{R}^2$ 为质心坐标，$\mathbf{b}_i$ 为边界框，$\mathbf{a}_i$ 为属性字典（如颜色、面积），$c_i \in [0, 1]$ 为节点检出置信度；
- **关系边** $e_{ij} = (v_i, v_j, r_{ij}, c_{ij}) \in \mathcal{E}$：描述实体间的空间拓扑约束。边置信度由节点置信度联合约束：$c_{ij} = \min(c_i, c_j)$；
- **形式化谓词提取**：
  $$\text{goal\_reached} \iff \exists e_{ij} \in \mathcal{E} \text{ s.t. } r_{ij} = \text{"touching"} \land \text{cat}(v_i) = \text{"agent"} \land \text{cat}(v_j) = \text{"target"}$$

### 1.2 参数化感知噪声模型

为定量评估 VLM 感知前端的不完美性对逻辑推理的影响，注入四类典型感知噪声：
1. **属性扰动（Attribute Noise）**：以概率 $p_{\text{attr}}$ 随机漂移节点颜色或类型属性；
2. **空间抖动（Spatial Jitter）**：质心与边界框添加各向同性高斯漂移 $\Delta \mathbf{p} \sim \mathcal{N}(0, \sigma_{\text{jitter}}^2 \mathbf{I})$；
3. **漏检（Missed Detection）**：以概率 $p_{\text{miss}}$ 丢失目标实体（假阴性）；
4. **幻觉虚警（Hallucination / False Alarm）**：以概率 $p_{\text{false}}$ 注入低置信度虚假节点（假阳性）。

随着噪声强度的增加，节点置信度自动进行贝叶斯折现：$c_i \leftarrow \max(0.1, 1.0 - 0.5 \|\Delta \mathbf{p}\|)$。

### 1.3 弥散空假设 $h_\varnothing$ 异常阻断

当场景图中的置信度均值跌落至安全阈值以下，或关键决策目标发生漏检时，系统立即将场景标记为 `is_corrupted = True`。  
此时 System 2 自动激活**弥散空假设 $h_\varnothing$**，将候选假说的验证结论置为不确定，拒绝将未经可信感知的候选程序晶化入长期语义记忆，从而从根源上捍卫 **0.00% 假验证率**。

## 2. 实验对照方案

对比两大技术路线：

1. **Arm P1 (Naive Perception / 脆弱像素与精确比对)**：
   - 依赖严格像素矩阵/坐标相等比较；
   - 无置信度加权，无图拓扑容错；
   - 无 $h_\varnothing$ 空假设异常屏蔽机制。

2. **Arm P2 (L3 Robust Scene Graph Front-End / 本工作完整体系)**：
   - 将原始像素/模拟器离散化提取为语义场景图与空间谓词；
   - 允许空间与属性的轻量模糊匹配（归一化图距离 $\le 0.20$）；
   - 强噪声或破损输入下 100% 激活 $h_\varnothing$ 保护。
