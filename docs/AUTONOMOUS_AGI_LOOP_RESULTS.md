## 2. 核心子系统理论与实现细节

### 2.1 双通道冗余传感器流与贝叶斯融合 (`RedundantSensorStream`)

在真实物理或复杂模拟环境下，单传感器不可避免地会出现漂移、硬件卡死、光照突变或对抗性干扰。系统设计了主通道传感器 $S_{\text{primary}}$ 与审计通道传感器 $S_{\text{audit}}$：
- **欧氏视差度量**：
  $$\Delta_{\text{sensor}} = \|\mathbf{x}_{\text{primary}} - \mathbf{x}_{\text{audit}}\|_2$$
- **视差异常保护门控**：
  若 $\Delta_{\text{sensor}} > \tau_{\text{disparity}}$（实验设定阈值为 0.35），系统立即标记 `sensor_fault_detected = True`，切断下游驱动器的执行权限（`is_safe_to_actuate = False`），并激活弥散空假设 $h_\varnothing$；
- **多维高斯贝叶斯无偏估计**（在视差安全区间内）：
  $$\hat{\mathbf{x}} = \frac{\sigma_{\text{audit}}^2 \mathbf{x}_{\text{primary}} + \sigma_{\text{primary}}^2 \mathbf{x}_{\text{audit}}}{\sigma_{\text{primary}}^2 + \sigma_{\text{audit}}^2}, \quad \hat{\sigma}^2 = \frac{\sigma_{\text{primary}}^2 \sigma_{\text{audit}}^2}{\sigma_{\text{primary}}^2 + \sigma_{\text{audit}}^2}$$

### 2.2 密码学防篡改审计协议 (`SafetyAuditProtocol`)

智能体在长程连续自演进过程中，每一次算子晶化、适配层提交、安全介入以及参数回滚都必须具备可溯源性与抗审查性：
- **哈希链不可逆账本**：
  每个账本区块的哈希计算定义为：
  $$H_k = \text{SHA256}\left( H_{k-1} \,\|\, \text{record\_id}_k \,\|\, \text{event\_type}_k \,\|\, \text{actor}_k \,\|\, \text{SHA256}(\text{payload}_k) \,\|\, t_k \right)$$
  任何攻击者或模型自身若试图篡改历史经验或伪造验证状态，都会导致整条哈希链下游断裂（`verify_ledger_integrity() -> False`）。
- **时效性 HMAC 授权令牌机制**：
  对于紧急停机、高风险执行等越权指令，引入监管者非对称 HMAC 动态签名：
  $$\text{Token} = \text{operation} \,\|\, t_{\text{expire}} \,\|\, \text{HMAC-SHA256}(K_{\text{secret}}, \text{operation} \,\|\, t_{\text{expire}})$$
  系统在毫秒级自动核验签名有效性与有效期（$t_{\text{current}} \le t_{\text{expire}}$）。

### 2.3 自主闭环协调器 (`AutonomousEngine`)

主协调器协调日间醒来（Wake Phase）与夜间睡眠（Sleep Phase）的连续交替：
1. **工作记忆隔离**：进入每项任务前由 `working_memory.initialize_task()` 注入上下文；任务执行完毕后强制调用 `working_memory.clear()`，保证跨任务零记忆泄漏；
2. **多层级经验流转**：
   - 快速假设：短期驻留于工作记忆；
   - 验证轨迹：完整树状结构无损压入 Episodic Memory；
   - 通用算子：提炼为抽象 AST 并注册入 Semantic Memory 的活跃 Hot Tier；
3. **昼夜节律调度**：
   - 白天进行高吞吐量 CEGIS 探索与主动证伪；
   - 夜间触发参数重放巩固、半衰期记忆修剪与回归门审计，通过后原子提升系统版本号。
